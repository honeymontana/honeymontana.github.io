# Локальные шрифты

Основные шрифты русской версии:

- Manrope Variable WOFF2 (Latin/Cyrillic) — основной текст, SIL Open Font License 1.1.
- Russo One WOFF2 (Latin/Cyrillic) — крупные русские display-заголовки, SIL Open Font License 1.1.
- Fira Code 400 Latin/Cyrillic — технические подписи, SIL Open Font License 1.1.

Также в папке оставлены Outfit и Paytone One из визуального референса. Они
содержат только Latin-глифы и не используются для русских заголовков.

На референсном сайте display-заголовки набраны Cubano Regular. Это коммерческий
шрифт Lost Type без кириллицы, поэтому его файл намеренно не распространяется в
этом проекте.
