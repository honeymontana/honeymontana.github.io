Каждый раз, когда ты открываешь приложение банка и оно **не крашится** при переводе денег — это работа QA-инженера. Каждый раз, когда сайт корректно считает скидку, а форма не даёт отправить пустой email — это тоже он.

В этой статье разложим, чем реально занимается QA (не тем, что показывают в мемах), какие навыки нужны и как войти в профессию с нуля.

## Кто такой QA-инженер

**QA (Quality Assurance)** — специалист, который отвечает за качество продукта. Не «ищет баги» — а **предотвращает** их появление.

Есть три близких, но разных роли:

| Роль | Что делает | Зарплата junior, ₽ |
|---|---|---|
| **Tester** | Прогоняет тест-кейсы вручную | 60–90k |
| **QA Engineer** | Проектирует тесты, автоматизирует, пишет отчёты | 100–150k |
| **QA Automation** | Пишет автотесты на Python/Java/JS | 150–250k |

В вакансиях эти названия часто путают. Ориентируйся не на тайтл, а на список обязанностей.

## Что делает QA каждый день

Типичный день выглядит примерно так:

1. Утром смотрит новые задачи в Jira.
2. Читает требования от аналитика.
3. Пишет тест-кейсы (сценарии проверки).
4. Прогоняет их на новом билде.
5. Найденные баги заводит в Jira с подробным описанием.
6. Помогает разработчикам воспроизвести баг.
7. Верифицирует исправления.

Плюс — писать автотесты, если ты уже вырос из ручного тестирования.

## Какие навыки нужны

### Hard skills (обязательно)

- **Теория тестирования** — виды, уровни, техники (граничные значения, классы эквивалентности, pairwise).
- **SQL** на уровне SELECT/JOIN/GROUP BY:

```sql
SELECT user_id, COUNT(*) AS orders
FROM orders
WHERE created_at >= '2026-01-01'
GROUP BY user_id
HAVING COUNT(*) > 5;
```

- **HTTP и REST API** — методы, коды ответов, что такое JSON.
- **Postman** или аналог для ручного тестирования API.
- **Git** на уровне clone / branch / commit / push / pull.
- **DevTools** браузера — Network, Console, Elements.

### Hard skills (для automation)

- Один из языков: **Python, Java или JavaScript**. Для новичков рекомендую Python.
- Фреймворки: **pytest**, **Selenium** / **Playwright**.
- CI/CD базово: что такое GitHub Actions или GitLab CI.

Простой автотест на Python + Playwright выглядит так:

```python
from playwright.sync_api import sync_playwright

def test_login_shows_error_on_wrong_password():
    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page()
        page.goto("https://example.com/login")

        page.fill('input[name="email"]', "user@example.com")
        page.fill('input[name="password"]', "wrong-password")
        page.click('button[type="submit"]')

        error = page.locator(".error-message")
        assert error.is_visible()
        assert "неверный пароль" in error.text_content().lower()

        browser.close()
```

### Soft skills

- **Внимательность** к деталям — половина работы.
- **Умение задавать правильные вопросы** аналитику и разработчику.
- **Аккуратность в описании багов** — плохой баг-репорт заставит разработчика ходить к тебе 5 раз.

## Как войти в профессию с нуля

Реалистичный путь занимает **3–6 месяцев** при 2–3 часах в день:

1. **Месяц 1** — теория тестирования (книга Куликова «Тестирование программного обеспечения. Базовый курс»).
2. **Месяц 2** — SQL, HTTP, Postman. Практика на тестовых API.
3. **Месяц 3** — Git, DevTools, первые собеседования на позицию ручного тестировщика.
4. **Месяцы 4–6** — Python + pytest + Selenium/Playwright, автоматизация.

> Совет: **не жди, пока «выучишь всё»**. Ходи на собеседования уже через 2 месяца. Каждое собеседование — бесплатный урок, где тебе покажут, что ещё нужно подтянуть.

## Сколько зарабатывает QA в 2026

По данным hh.ru на середину 2026 года (Москва + удалёнка):

- **Junior** (0–1 год): 80–130k ₽
- **Middle** (1–3 года): 150–250k ₽
- **Senior** (3+ года): 250–400k ₽
- **Automation Middle+**: 200–350k ₽

Удалёнка есть примерно у 60% вакансий. Регион почти не влияет на зарплату, если работа удалённая.
